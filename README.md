# homebrew-skritch

Homebrew tap for [Skritch](https://github.com/archcorsair/skritch) — a fast,
local-only screenshot annotation tool for macOS in the spirit of Skitch.

## Install

```sh
brew tap archcorsair/skritch
brew install --cask skritch
```

Releases are Developer ID signed and notarized.

The cask is updated automatically by Skritch's release workflow — issues with
the app itself belong in the [main repo](https://github.com/archcorsair/skritch/issues).
